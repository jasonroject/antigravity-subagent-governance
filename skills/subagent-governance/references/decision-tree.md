# 子代理调用决策自检与常见反模式 (Decision Tree & Anti-Patterns)

本文档提供详细的自检问卷与常见反模式对照，帮助 Agent 在决定是否调用 `invoke_subagent` 时进行客观评估。

---

## 1. 快速自检清单 (Pre-flight Checklist)

在考虑调用任何子代理前，必须逐项回答以下问题：

| 序号 | 核心问题 | 判定标准 |
| :---: | :--- | :--- |
| **Q1** | 用户是否明确要求使用子代理？ | 若用户未提及，**判定为否**。 |
| **Q2** | 当前任务能否用主 Agent 的工具链（`run_command`、`read_file`、`write_file` 等）直接完成？ | 若能直接执行，**严禁派发**。 |
| **Q3** | 派发子代理是否会造成关键上下文丢失？ | 子代理默认不继承主对话的全部临时状态，若需传递大量背景，**严禁派发**。 |
| **Q4** | 预计消耗的额外 Token 和时间是否显著高于直接执行？ | 若派发带来的通信与初始化开销超过任务本身，**严禁派发**。 |

---

## 2. 常见反模式对照表 (Anti-Patterns vs Correct Practices)

| 场景 | ❌ 错误反模式 (派发子代理) | ✅ 正确做法 (主 Agent 直通) |
| :--- | :--- | :--- |
| **搜索代码** | 派发 `research` 子代理在代码库中搜索函数调用。 | 主 Agent 直接调用 `run_command` 运行 `rg` 或通过 `search_files` 定位。 |
| **修改 Bug** | 派发 `self` 子代理修改一个文件并提交。 | 主 Agent 调用 `edit_file` 或 `write_file`，并运行相关测试。 |
| **执行测试** | 启动一个子代理运行 `npm test` 并等待其汇报。 | 主 Agent 调用 `run_command` 直接执行测试，并分析控制台输出。 |
| **网页浏览** | 频繁派发新的子代理分别打开不同的网页。 | 优先遵循全局 `ego-browser` 技能，通过 TaskSpace 批量或连续管理标签页。 |
| **多角度审查** | 无用户指令时自行派发 3 个子代理做代码审查。 | 主 Agent 在自身的思维链中多视角评估，直接在回复中汇总输出。 |
